# mometin_trader

60秒間のランダム相場で、ロング・ショートの売買を楽しむブラウザーゲームです。元のゲームを参考に独自実装しています。

## 自分のパソコンで遊ぶ

Windowsでは **start-game.cmd をダブルクリック**してください。普段使っているブラウザーでゲームが開きます。

index.html をブラウザーで直接開いても遊べます。インストール、Node.js、サーバー、ChatGPTへのログインは不要です。ファイルを移動するときは index.html と game.js を同じフォルダーに置いてください。

## 遊び方

- STARTを押すと3秒のカウントダウン後、60秒の勝負が始まります。
- BUYはロング、SELLはショート。1回1,000通貨、同じ方向には最大10回まで追加できます。
- 決済で保有ポジションを一括決済します。反対方向の注文では決済してから反転します。
- 60秒終了時に自動決済し、結果を表示します。
- ×0.5〜×4で相場の進む速さを変更できます。勝負時間は60秒です。
- 一時停止、効果音の切り替え、今日のチャレンジ、同じ相場の再プレイに対応しています。
- Enterで開始・一時停止、↑で買い、↓で売り、Spaceで決済できます。スマートフォンではチャートの上下フリックでも注文できます。

成績はブラウザーの保存領域に保存されます。ブラウザーや開く場所を変えると、別の成績になります。架空の資金を使うゲームです。

## GitHubで公開する

1. GitHub Desktopで「File → Add local repository」からこのフォルダーを追加します。
2. 「Publish repository」でGitHubに公開します。誰でもアクセスできるようにする場合は公開リポジトリを選びます。
3. GitHubのリポジトリ画面で「Settings → Pages」を開きます。
4. 「Build and deployment」のSourceで「Deploy from a branch」を選びます。
5. Branchを「main」、フォルダーを「/ (root)」にしてSaveします。
6. デプロイが完了すると同じ画面にゲームのURLが表示されます。

公開URLの例: https://YOUR-ACCOUNT.github.io/mometin_trader/

公開後はブラウザーからURLを開くだけで遊べます。「同じ相場のURLをコピー」で相場を共有できます。ローカル起動中のURLは、自分のパソコンのファイルを指します。

## ファイル

- index.html: 画面とスタイル
- game.js: 相場生成、売買処理、チャート、成績保存
- start-game.cmd: Windowsの既定ブラウザーで起動
- .nojekyll: GitHub Pagesで静的ファイルをそのまま配信

外部ライブラリー、外部フォント、外部通信は使用しません。GitHub Pages以外の静的ホスティングでも公開できます。

## ESP32による強制損切り

GPIO13のL → HでUSB経由の強制決済に対応しています。Arduino IDE用スケッチと配線・接続方法は [ESP32_SETUP.md](ESP32_SETUP.md) を参照してください。USB連携にはPC版Chrome / Edgeが必要です。

## ボラティリティの変更

画面上部の「ボラティリティ」で値動きの大きさを×0.25・×0.5・×1（標準）・×2・×4に変更できます。ゲーム中は次の値動きから反映され、現在価格や建値は変わりません。開始前はチャート全体を選んだ値幅で再生成します。速度とは独立した設定で、勝負時間は60秒のままです。設定は共有URLのvolに含まれます。同じ相場を完全に再現したい場合は、ゲーム中に設定を変えずに遊んでください。

## ポジション損失の警告音

「警告する損失率」に正の数を入力します。初期値20なら、ポジションの損益率が−20%を下回った際に警告音が1回鳴ります。0.1〜100%の範囲、0.1%単位で変更でき、同じブラウザーに設定を保存します。損益率は含み損益 ÷（平均建値 × 保有通貨数）× 100で、ショートにも対応します。口座全体の損失率ではありません。

警告中もポジションを保有し続けます。損失が設定値以内に戻ってから再び超えると再度鳴ります。「音: OFF」では警告音も消音しますが、画面の警告は表示します。一時停止中にも設定変更を反映します。損切りの操作・ESP32による強制決済と併用できます。
